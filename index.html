CSS Layouts

determinan cómo se ordenan, posicionan y dimensionan los elementos de una página web en relación con los demás y con la pantalla del navegador

Animaciones

Las animaciones CSS permiten cambiar el aspecto y la posición de un elemento web de forma suave entre dos o más estados usando la regla @keyframes y sin necesidad de JavaScript

Sass

Sass es un preprocesador de CSS que añade superpoderes como variables, anidamiento y mixins para escribir estilos más ordenados y escalables

Curso completo de CSS3. ¡Domina CSS de una vez por todas!

El CSS (Hojas de Estilo en Cascada) es un lenguaje de diseño gráfico que se utiliza para definir y estructurar la apariencia visual de los documentos escritos en HTML o XML, permitiendo controlar de manera precisa aspectos como los colores, las tipografías, los márgenes, los espaciados, las dimensiones y la distribución de los elementos en la pantalla, con la enorme ventaja de separar el contenido estructural de su presentación estética y posibilitar que un único archivo de estilos modifique el diseño de múltiples páginas de un sitio web de forma simultánea y adaptable a diferentes dispositivos
